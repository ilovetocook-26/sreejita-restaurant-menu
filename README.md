# 🍽️ Restaurant QR Menu

A web-based digital restaurant menu system developed using **PHP and MySQL**. Customers can scan a QR code to access the restaurant menu, view food items, add items to a shopping cart, and place orders online.

## 📌 Project Overview

The Restaurant QR Menu is designed to provide a simple and convenient digital menu experience for customers.

The system has two main sections:

* 👤 **Customer Section** – Browse the menu, manage cart items, and place orders.
* 🔐 **Admin Section** – Manage restaurant-related information and orders.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment:** XAMPP
* **Database Management:** phpMyAdmin
* **Session Management:** PHP Sessions

## ✨ Features

### 👤 Customer Features

* View digital restaurant menu
* Browse food items
* Add items to cart
* Increase or decrease item quantity
* View cart
* Calculate order subtotal
* Place orders

### 🔐 Admin Features

* Admin login
* Admin dashboard
* Manage restaurant data
* View and manage orders

## 🗄️ Database

The project uses **MySQL** to store application data.

The database was developed and tested using **phpMyAdmin** through the XAMPP environment.

## 🚀 How to Run Locally

### 1. Install XAMPP

Install XAMPP and start:

* Apache
* MySQL

### 2. Copy the project

Place the project folder inside:

```text
C:\xampp\htdocs\
```

### 3. Create the database

Open:

```text
http://localhost/phpmyadmin
```

Create the required MySQL database and import the project's SQL database file.

### 4. Configure the database connection

Update the database connection details in the PHP database configuration file according to your local MySQL setup.

### 5. Run the project

Open your browser and visit:

```text
http://localhost/sreejita-restaurant-menu/
```
